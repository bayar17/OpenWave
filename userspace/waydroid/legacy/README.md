# Retired catalog prototype

`openwave_android_provider.py` was recovered unchanged from the staged Waydroid
package during the 2026-11-06 audit. It is not the desktop importer described in
the old integration notes, and current appd exposes none of its catalog methods.
The upstream session no longer imports it. Keep this source for review and
possible reuse outside the upstream package; it is not installed or linked.

Its launch capability deliberately remains disabled. It is not evidence of
working Android startup, shortcuts, icons or surface identity.
